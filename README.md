# AFK Bank 3.0 — віртуальна економічна гра

Адаптивний сайт на HTML/CSS/JavaScript та Netlify Functions + PostgreSQL. Баланси, покупки, кредити, перекази, нагороди й перевірки виконуються на сервері.

## Функції

- **Акаунти:** реєстрація, вхід, аватарки, сесії, профіль, рівні та прогрес.
- **Економіка:** віртуальні гривні, щоденний бонус (50 000 грн × множник рівня), перекази, рейтинг.
- **Мініігри:** швидка математика (+5 очок), пам’ять (+6 очок), вгадай число (+4 очки). Завдання генерує та перевіряє сервер. Мініігри не мають ставок і не видають грошей.
- **Фокус-сесії:** 30 секунд → 5 очок прогресу; кулдаун 2 години.
- **Банк між гравцями:** кредитні пропозиції та заявки, прийняття, відхилення, контрпропозиції, повідомлення сторонам, погашення та прострочення.
- **Правила кредиту:** 1 000–2 000 000 000 грн; ставка 0,1–70%; термін 1–10 днів. Відсоток нараховується один раз на основну суму: `ceil(сума × ставка / 100)`. Дострокове погашення не має штрафу, але відсоток не скасовується. Після строку додається 1% основної суми за кожен розпочатий день прострочення, максимум 30% основної суми. Це прозорі правила саме цієї версії.
- **Бізнес:** купівля одного бізнесу та отримання фіксованого доходу раз на 24 години.
- **Майно:** автосалон із відомими цінами, гараж, захист гаража, 25 об’єктів нерухомості та 15 бізнесів.
- **Ринок:** продаж/купівля автомобілів, нерухомості й бізнесів за вказаною ціною; продавець отримує кошти, покупець — майно.
- **Косметичні ролі:** створення за 10 000 грн, виставлення на продаж, придбання та вибір активного титулу. Косметичні ролі не дають прав адміністратора.
- **Промокоди:** адміністратори створюють коди з фіксованою винагородою та лімітом використань; один гравець активує код лише один раз.
- **Повідомлення:** вхідні повідомлення від адміністрації та банківські сповіщення.
- **Адмінпанель:** видача/встановлення балансу, стаміна, блокування банку, видача авто й бізнесу, повідомлення, промокоди, журнал дій. Лише власник може призначати або знімати адміністраторів.

## Розгортання на Netlify

1. Розпакуй архів і завантаж **вміст папки `afk-bank`** у GitHub-репозиторій.
2. У Netlify імпортуй цей репозиторій. Publish directory має бути `public`; каталог функцій — `netlify/functions`.
3. Підключи PostgreSQL у **Data & Storage → Database**.
4. Виконай новий deploy. Міграція `0002_expand_gameplay.sql` додає нові таблиці та поля, не видаляючи користувачів, баланси чи старі автомобілі.
5. Перевір `/api` на своєму домені. Має повернутися JSON із `ok: true` та версією `3.0.0`.

## Сумісність зі старою базою

Код підтримує `NETLIFY_DATABASE_URL` (старе підключення Neon), `NETLIFY_DB_URL` (Netlify Database) та `DATABASE_URL` (звичайний PostgreSQL). Якщо в старому проєкті `NETLIFY_DATABASE_URL` вказує на базу з попередніми акаунтами, не видаляй її без перенесення даних. Окрема нова база не міститиме старих користувачів автоматично.

За потреби задай `OWNER_NICK` у Netlify Environment variables. Якщо її не задано, власником стає перший зареєстрований користувач. Не публікуй рядки підключення чи секрети у GitHub.

## Локальний запуск

```bash
npm install
npx netlify dev
```

Потрібне активне підключення до PostgreSQL через одну зі змінних середовища вище.
