# AFK Bank 2.0 — безпечна економічна гра на Netlify

## Що є в цій версії

- Реєстрація, вхід і збереження акаунтів у PostgreSQL.
- Баланс у віртуальних гривнях, щоденний бонус і прогрес рівнів.
- Перекази між гравцями та рейтинг за балансом.
- Автосалон із фіксованою ціною кожної моделі; жодних платних випадкових кейсів.
- Гараж, вибір активного автомобіля, нерухомість і бізнеси.
- 30-секундна фокус-сесія за 5 очок прогресу — без ставок і грошових виграшів.
- Адмінпанель, журнал дій, керування балансом і стаміною.
- Власник має найвищий рівень доступу; лише власник може призначати або знімати адміністраторів.
- Адаптивний інтерфейс для телефонів і комп'ютерів.

У початковому ZIP не було реалізації банківських кредитів, ринку між гравцями, магазину ролей, гаражного захисту, промокодів та частини адміністративних команд. Я не додавав вигаданих правил для цих систем.

## Розгортання на Netlify

1. Розпакуй ZIP та завантаж **вміст папки `afk-bank`** у свій GitHub-репозиторій.
2. У Netlify відкрий **Add new project → Import an existing project** та підключи цей репозиторій.
3. Переконайся, що в налаштуваннях збірки Publish directory = `public`. Версія Node задана в `netlify.toml`.
4. Створи або підключи PostgreSQL у Netlify: **Data & Storage → Database**. Netlify застосує SQL-міграцію з `netlify/database/migrations/` під час deploy.
5. Зроби новий deploy і дочекайся статусу Published.
6. Відкрий адресу сайту. Для перевірки API можна відкрити `https://ТВІЙ-САЙТ.netlify.app/api` — має повернутися JSON зі статусом `ok: true`.

### Важливо про стару базу та акаунти

Ця версія підтримує обидва способи підключення:

- Старий Netlify DB / Neon: `NETLIFY_DATABASE_URL`.
- Новий Netlify Database: `NETLIFY_DB_URL`.

Якщо в налаштуваннях Netlify ще є `NETLIFY_DATABASE_URL`, сайт спочатку використовуватиме її, щоб не втратити акаунти зі старої бази. Не видаляй цю змінну, доки не перенесеш дані. Нова база, створена окремо, не містить автоматично старих користувачів.

Якщо це новий сайт без попередньої бази, достатньо створити Netlify Database; код автоматично використає `NETLIFY_DB_URL`.

### Власник сайту

За бажанням додай у **Site configuration → Environment variables** змінну `OWNER_NICK` зі своїм ніком. Якщо її не задано, власником автоматично стане перший зареєстрований користувач. Не публікуй паролі та рядки підключення до бази в GitHub.

## Локальний запуск

```bash
npm install
npx netlify dev
```

Для локального запуску потрібна база даних Netlify або PostgreSQL, підключена через відповідну змінну середовища.
