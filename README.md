# AFK Bank 6.0

Повноекранна адаптивна браузерна економічна гра на HTML/CSS/JavaScript + Netlify Functions + Netlify Database/Postgres.

## Що змінилося у 6.0

- Щотижневі президентські вибори: кожного понеділка 13:10–14:20 за `Europe/Kyiv`.
- Кандидатура з назвою партії та програмою; внесок `100 000 × рівень гравця`.
- Голосування за кандидатів, за себе голосувати не можна; у разі нічиєї між кандидатами переможець визначається випадково на сервері.
- О 14:20 підсумок записується в базу; новий президент отримує доступ до окремого кабінету.
- Кабінет президента: казна `100 000 000 грн` для нової/початкової бази, податок бізнесу 0–15%, зняття до 5 000 000 грн раз на 48 годин, премія кожному гравцю до 5 000 000 грн, звернення до всіх гравців.
- Нічна подія: якщо баланс більший за 1 000 000 грн і гравець не має житла, раз на київську календарну добу сервер перевіряє 15% шанс пограбування на 100 000–800 000 грн. Подія показується в системних сповіщеннях.
- Новим користувачам після реєстрації показується окреме вікно дозволу на сповіщення.
- Додано Service Worker і Web Push. Для push, який приходить навіть коли сайт закритий, потрібно задати VAPID environment variables у Netlify (див. нижче). Без них працюють внутрішні сповіщення, polling у відкритій вкладці та повідомлення при наступному вході.
- Мобільна навігація: знизу лише Профіль, Міні-ігри, Інвентар, Ринок; решта розділів відкриваються кнопкою-гамбургером у правому верхньому куті. На ПК залишається ліва панель.
- Рейтинг перенесено в профіль; гравців можна відкривати та переглядати їхні авто, нерухомість і бізнеси.
- Прибрано окремі розділи «Повідомлення» та «Ролі». Адмінські повідомлення надходять як системні сповіщення; в адмінпанелі доступне приватне повідомлення та оголошення всім.
- Бізнес показує погодинний дохід. Netlify Scheduled Function та серверна звірка на вході нараховують повні години навіть коли гравець офлайн; президентський податок зараховується до казни.
- Додано 25 згенерованих автомобільних фото-карток; каталог зіставляє моделі з фотографіями відповідного бренду/класу. Додано окрему графіку гаражного кейса.
- Щоденний бонус видається строго раз на 24 години на сервері; стаміна не обходить це обмеження.

## Ігри та випадковий контент

У розділі мініігор залишено безкоштовну анімацію монетки без ставок, втрат, грошових виграшів або очок за прогноз. «Печенька» та «Вгадай число» — лише дружні матчі без грошових ставок і виплат. Грошові азартні ігри, рулетка, платні випадкові кейси/loot-box відкриття, швидка математика й тренування пам'яті не входять до цієї безпечної збірки. Автомобілі купуються напряму за фіксованою ціною.

## Розміщення на Netlify

1. Розпакуй ZIP. У GitHub завантаж вміст папки `afk-bank` у корінь репозиторію (заміни файли попередньої версії).
2. У Netlify залиш підключену ту саму базу даних. Проєкт підтримує `NETLIFY_DB_URL`, стару `NETLIFY_DATABASE_URL` та `DATABASE_URL`.
3. Переконайся, що Netlify будує Node.js 22.
4. Опублікуй production deploy. Scheduled Functions автоматично працюють за розкладом лише на опублікованому deploy, а не на Deploy Preview/branch deploy.
5. Відкрий `https://твій-сайт.netlify.app/api`. Очікувана відповідь містить `ok: true`, `version: "6.0.0"` та `timezone: "Europe/Kyiv"`.

Схема бази оновлюється сумісно через `init()` у API. Міграція `0007_elections_notifications_and_robbery.sql` залишена в `netlify/database/migrations` як документована SQL-міграція. Не видаляй базу чи її старі таблиці: акаунти, сесії, баланси, інвентар та майно зберігаються.

## Push-сповіщення, коли браузер закритий

Для повноцінних Web Push повідомлень створи VAPID key pair командою:

```bash
npx web-push generate-vapid-keys
```

У Netlify → Site configuration → Environment variables задай:

- `VAPID_PUBLIC_KEY` — public key із команди;
- `VAPID_PRIVATE_KEY` — private key із команди (не публікуй його й не додавай у GitHub);
- `VAPID_SUBJECT` — контактний рядок, наприклад `mailto:твоя-поштова-адреса`.

Після цього зроби новий production deploy. Підписки користувачів реєструються через `/api` і таблицю `push_subscriptions`. HTTPS обов'язковий. На iPhone Web Push у Safari доступний для вебзастосунку, доданого на головний екран (залежно від версії iOS); у налаштуваннях браузера має бути дозволено сповіщення.

## Час і фонова робота

`netlify/functions/maintenance.mjs` запускається кожні п’ять хвилин. Netlify виконує cron за UTC, а код перетворює поточний час до `Europe/Kyiv`, тому вибори прив'язані до київського понеділка та коректно проходять при переходах на літній/зимовий час. Netlify scheduled functions запускаються тільки на опублікованих production deploys.

Фонова функція обробляє погодинні доходи бізнесів (зарахування з технічним лагом до п’яти хвилин), гаражі, щоденну подію пограбування, банківські строки та відкриття/закриття виборів. Якщо кількість користувачів суттєво зросте, обробку всіх гравців у `maintenance` варто перевести на пакетні SQL-операції або розбити на черги через background functions.

## Перевірки

Перед пакуванням перевірено синтаксис:

- `netlify/functions/api.mjs`
- `netlify/functions/maintenance.mjs`
- клієнтського JavaScript у `public/index.html`
- `public/sw.js`

Живий зв'язок з твоєю базою та реальні Web Push доставки не можна перевірити без доступу до твого Netlify проєкту та секретів VAPID.
