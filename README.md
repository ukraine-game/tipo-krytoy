# AFK Bank 7.1

Адаптивна браузерна економічна гра на HTML/CSS/JavaScript + Netlify Functions + PostgreSQL/Netlify Database.

## Оновлення 7.0

- Додано соло-режим «Вгадай число»: легко 1–3, середньо 1–5, важко 1–10, неможливо 1–50. Секретне число генерується на сервері, кількість спроб обмежена, результат і XP перевіряються та записуються сервером.
- Додано п'ять гаражних комплектів із різними зображеннями. Кожен комплект має фіксований, відомий до покупки автомобіль і ціну. Це гарантовані набори, не платний випадковий дроп; прихованих шансів або рулетки немає.
- Для кожної з 85 моделей каталогу створено окремий файл зображення, тому картки автосалону, гаража, інвентарю та профілів не використовують один і той самий файл. Це унікальні візуальні варіанти, побудовані на 25 вихідних згенерованих автомобільних рендерах; це не 85 окремо сфотографованих реальних моделей.
- Розширено події зі сповіщеннями: запрошення та прийняття матчів, результат матчу, перекази, покупки авто/нерухомості/бізнесу, покупки комплектів і операції ринку. Події записуються в inbox та відправляються через Web Push, якщо налаштовані всі VAPID-ключі.
- Додано налаштування частоти повідомлень про бізнес-дохід: 1 година, 2 години, 5 годин, 1 день або ніколи. Погодинне нарахування не зупиняється, навіть якщо повідомлення вимкнено.
- Заплановане обслуговування тепер також завершує прострочені матчі, включно з повідомленням обом учасникам, навіть коли вони офлайн.
- Polling сповіщень у відкритій вкладці скорочено до 8 секунд; при поверненні у вкладку виконується додаткова перевірка.
- Версія API: `7.1.0`.

## Важливо щодо мініігор і комплектів

Монетка залишається безкоштовною анімацією без ставок і грошових виплат. «Печенька» та гра проти друга «Вгадай число» — дружні матчі без грошових ставок. Соло-режим «Вгадай число» дає лише фіксовані очки прогресу за успішне проходження. Комплекти гаража містять конкретну модель автомобіля, яка показується перед покупкою. У цій версії немає грошових ставок, множників грошових виграшів чи платних випадкових loot-box механік.

## Розгортання на Netlify

1. Розпакуй ZIP і завантаж **вміст** папки `afk-bank` у корінь GitHub-репозиторію, замінивши старі файли.
2. Не видаляй попередню базу даних та її environment variables. Підтримуються `NETLIFY_DB_URL`, `NETLIFY_DATABASE_URL` і `DATABASE_URL`.
3. Переконайся, що на Netlify використовується Node.js 22.
4. Дочекайся успішного production deploy.
5. Перевір `https://твій-сайт.netlify.app/api`: очікується `ok: true`, `version: "7.1.0"` і `timezone: "Europe/Kyiv"`.

Схема нових таблиць також створюється ідемпотентно через `init()` в API. Документовані SQL-міграції: `netlify/database/migrations/0008_solo_guess_and_live_events.sql` та `0009_business_notification_preferences.sql`. Старі таблиці й акаунти не видаляються.

## Web Push: повідомлення Chrome, коли сайт закритий

Щоб push працював навіть за закритої вкладки, створи VAPID key pair:

```bash
npx web-push generate-vapid-keys
```

У Netlify → Site configuration → Environment variables задай:

- `VAPID_PUBLIC_KEY` — public key;
- `VAPID_PRIVATE_KEY` — private key (секретний, не коміть у GitHub);
- `VAPID_SUBJECT` — наприклад `mailto:твоя-поштова-адреса`.

Після збереження змінних зроби новий production deploy. Користувач має дозволити повідомлення в браузері. Без цих змінних in-app сповіщення продовжують працювати, а push при закритому браузері — ні. HTTPS обов'язковий. На iPhone для Web Push потрібне встановлення вебзастосунку на головний екран і підтримувана версія iOS.

## Фонові події

`netlify/functions/maintenance.mjs` запускається кожні п'ять хвилин. Він обробляє погодинний дохід бізнесів, вибори, нічні події, банківські строки та завершення матчів. Планові функції Netlify працюють на опублікованому production deploy, не на Deploy Preview.

## Перевірки

У цій збірці перевіряються синтаксис API, maintenance function, клієнтського JavaScript та Service Worker, узгодженість каталогу автомобілів із 85 окремими картками зображень і цілісність ZIP. Реальну доставку push і роботу з конкретною базою можна підтвердити лише після розгортання на твоєму Netlify.
